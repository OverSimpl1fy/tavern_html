# Tavern 前端发布副本

本仓库保存与 `OverSimpl1fy/tavern` 配套的静态页面。编辑来源在主仓库，不在发布副本中独立修改。

当前唯一发布的德尔菲安前端位于 `delphian/`，使用原版层级、壮举、技能品质、MP/SP 与既有变量结构。入口与狐神为2611020842，状态页为2611020718，校验页沿用2610142244；狐神内嵌入口及配套页面。`delphian-dnd2024/` 已撤回发布，不再作为更新项目。

手机通过「Destiny 世界书与狐神预设更新」面板选择“德尔菲安”，再成套更新世界书与狐神即可。本仓库不包含用户数据或运行网关。发布记录见[CHANGELOG.md](CHANGELOG.md)。
